SEMC image drop-in folder
=========================

The site ships with SVG placeholders. To use real photography, add files here
with EXACTLY these names (JPG, ideally compressed to < 300 KB each). The pages
detect them automatically - no code changes needed.

  hero.jpg          Home page hero image (landscape, ~1200x900)
  about.jpg         Home "about" + About page intro image
  gallery-1.jpg ... gallery-6.jpg   About page gallery (4:3, ~1000x750)
  doctor-1.jpg ...  Used by doctors.php if profiles are added in config.php
  logo-semc.svg     Replace the placeholder logo (then set LOGO_IS_PLACEHOLDER=false in includes/config.php)

Only use photographs SEMC owns or has permission to publish. Never use
stock photos of "doctors" to imply they work at SEMC.
